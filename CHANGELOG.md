# Changelog

## 0.9.0-alpha.1

First public-source release of a previously local deployment.

- Pi AI subscription OAuth, encrypted credentials and rotation, model configuration and channel status.
- WeChat iLink, official QQ and local OneBot with allowlists, account binding and isolated conversations.
- Confirmed memory, continuing topics and opt-in initiative with quiet hours, persistent budgets and unanswered-contact suppression.
- Native QQ SILK voice, local recognition, optional Qwen and bounded media/document processing.
- Separately authenticated Codex CLI subscription image generation.
- Docker callback mapping and fresh-runtime/container checks.
- MIT license, dependency notices, privacy/authentication docs, contribution templates and CI.

Experimental: no real-time calls or QQ social posting; WeChat voice output disabled; bounded video/document extraction; new QQ phone media tests and another fresh GPU machine remain separate acceptance steps. No claim of OpenAI program approval or unlimited/shared quota.
